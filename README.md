# murmure-talents-tools

The maintainer tooling of the Murmure Talents Catalogue: `murmure-talents` (validate, diff, sign),
`murmure-talents-kit` (the Talent contract shared with the Relay) and `strict-json`.
This repository is generated from the private Murmure repository: please open issues here, but do not
expect pull requests to be merged directly. Licensed under MIT.

```sh
cargo install --git https://github.com/follabcorp/murmure-talents-tools --tag <tag> murmure-talents
```

Pin a `<tag>` (`v<date>-<short-sha>`, see the Tags page) rather than a branch.
